# Preparation voice imports

Export each recording as WAV, MP3, OGG, or AIFF and give it the exact cue ID shown in:

`Documentation/PREPARATION_NARRATION_SCRIPT.md`

Example: the recording for `prep.after-tv.guided` can be imported as:

`Assets/Resources/PreparationVoice/prep.after-tv.guided.wav`

The game finds these clips automatically. No Inspector assignment is required. Keep one spoken line per file and do not include the speaker label in the recording. Subtitles are supplied by the game.
