# SIBUCAO desktop candidate guide

Candidate source identifier being validated: **2026.09.30-b4-7-rc2**. The first development build succeeded, but is a local diagnostic package with unresolved startup issues. The corrected release package has not yet been built or accepted. Use a 16:9 display, with 1920×1080 as the reference.

Prepare at the home, pack chosen supplies and leave for the school. Inspect each junction before committing to a passage. A side passage has its own outcome; helping there does not confirm a rescue on the center route. Finish the selected work and reach its exit to record that passage. If progress is blocked, use Escape > Recover task or return to the unfinished junction.

| Action | Control |
| --- | --- |
| Move / look | WASD / mouse |
| Use, open, inspect, place | E |
| Carry / release | F |
| Put down / cancel | Q |
| Pack a carried supply | P |
| Bag | I or Tab |
| Guide / checklist | J |
| Run | Shift |
| Jump / rise in water / vehicle brake | Space |
| Dive | Ctrl or C |
| Rotate a held tool / change reach | R + mouse / wheel |
| Repeat narration | N |
| Pause / back; settings during preparation | Escape |
| Center vehicle view / wipers | C / V |

Settings > Controls remaps fourteen shared movement/action controls. Choosing an occupied binding swaps the two actions. Escape, Tab, B, G, C, V, N, Right Shift and function keys remain reserved. F carrying already toggles; toggle grip/assistance provides an alternative to sustained input during applicable work. Thirty-two live Input System, settings and debrief assertions passed, including duplicate-binding swaps and grip behavior; 12 preparation assertions pass at each of 720p and 1080p, including shared settings, FOV, restart and remapped guide controls. Maximum-text guide and inventory buttons have been visually checked.

Comfort settings provide text size, field of view, invert look, reduced flashes and reduced camera motion. Audio has separate master, speech, environment and effects controls. Subtitles remain independently available. Instructional narration uses action names instead of remappable keys; follow the on-screen prompt for your current binding. The regenerated voice/caption files passed consistency checks, and 78 live playback/PCM checks pass, including speech interruption and volume routing. A human listening assessment has not been performed.

At the school, check in with reception, review resident follow-up and supplies, then confirm the handover to see the assessment. Scores use caps of 1500 Preparedness, 1200 Evacuation, 1000 Decision-Making, 1000 Rescue Management and 300 Teamwork. These caps are not a promise that every route offers all points. Other categories contribute signed 30% secondary Decision-Making credit; Decision-Making does not credit itself a second time. Existing older-save totals are preserved.

The results separate completed physical actions from seeded outcomes. Assisted residents, designated safe-point delivery and confirmed shelter arrival are different states. Unresolved locations must still be reported. Questions for reflection: which earlier decision changed a later situation, and what would you prepare or report differently?

## Participant observation record

Record a participant code, candidate/build identifier, resolution/settings, role and difficulty. Record start/end time, time without progress, assistance requested, confusing prompts, abandoned tasks, recovery/save/resume attempts, arrival outcome and remaining defects. Obtain feedback on whether the participant can explain what their actions changed. Leave an observation blank when it was not measured; never substitute fixture timings for participant results.
